# Five Elements & Zodiac Fashion Skill - Documentation

## Introduction
This project is an AI fashion recommendation tool that combines traditional Chinese five elements and zodiac culture. By entering your birth date, gender, and occasion, you can get personalized lucky color matching and dressing suggestions.

## Usage
1.  Open the page, enter your birth date, gender, and occasion (Work/Date/Daily/Party/Sport)
2.  Submit the form, the system will analyze your five elements and zodiac attributes
3.  View your exclusive lucky color recommendations, outfit advice, and scene-based guides

## Technical Details
- Frontend: HTML/CSS/JS
- Backend: Node.js + Vercel Serverless Functions
- Core Logic: Five elements & zodiac attribute analysis + scene-based outfit matching algorithm
